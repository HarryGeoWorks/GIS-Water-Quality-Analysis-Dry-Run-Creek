# Scripts

ArcPy scripts for the Dry Run Creek water-quality workflow will be added here as the project develops.

Planned organization:

- `01_prepare_data.py` — inspect and standardize source tables
- `02_combine_years.py` — combine annual monitoring records
- `03_quality_control.py` — validation and QA checks
- `04_site_year_summary.py` — summarize monitoring parameters by site/year
- `05_spatial_analysis.py` — spatial and contextual analysis

File names may change as the workflow is refined.
